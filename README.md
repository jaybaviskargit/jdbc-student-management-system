# Student Management System

A console-based **Student Management System** developed using **Java, JDBC, MySQL, and Maven**.
The application allows users to manage student records through a simple menu-driven interface.

## 🚀 Features

* Add Student
* View Student
* Update Student
* Delete Student
* Exit Application

## 🛠️ Technologies Used

* **Java**
* **JDBC**
* **MySQL**
* **Maven**
* **Git & GitHub**

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/jaybaviskargit/jdbc-student-management-system.git
```

### 2. Open the project

Open the project in **VS Code** or any Java-compatible IDE.

### 3. Configure MySQL

Create the required database and student table in MySQL.

Update your JDBC connection details in the Java source code according to your local MySQL setup.

### 4. Build the Maven project

```bash
mvn clean install
```

### 5. Run the application

Run the main Java class from the project.
